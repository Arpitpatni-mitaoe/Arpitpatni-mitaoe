## 🚀 Projects

### 🚦 Traffic Light Controller
> *Digital Electronics Engineering Laboratory · Sem I / FY B.Tech. · Year 2025–26*
> *Dept. of Information Technology*

![Hardware](https://img.shields.io/badge/Digital_Logic-00599C?style=for-the-badge&logoColor=white)
![Hardware](https://img.shields.io/badge/Hardware-FF6F00?style=for-the-badge&logoColor=white)
![NE555](https://img.shields.io/badge/NE555_Timer-6DB33F?style=for-the-badge&logoColor=white)
![CD4017](https://img.shields.io/badge/CD4017_Counter-a78bfa?style=for-the-badge&logoColor=white)

**About:**
Designed and implemented a Traffic Light Controller using basic digital components — no microcontrollers involved. The system uses a **NE555 timer** in astable multivibrator mode as a clock source and a **CD4017 decade counter** to drive Red, Yellow, and Green LEDs in a fixed, continuous sequence.

**Key Highlights:**
- 🔴 Red → 🔴🟡 Red+Yellow → 🟢 Green → 🟡 Yellow → 🔴 Red (repeating sequence)
- Boolean equations: `R = Q9`, `Y = Q4`, `G = Q5+Q6+Q7+Q8`
- Circuit implemented on breadboard using digital ICs
- Clock operated continuously without stopping; results verified and correct

**Team:** Arpit Patni · Akash Pujari · Vedant Dere
